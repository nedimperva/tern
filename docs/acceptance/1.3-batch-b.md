# Batch B (small UX): acceptance checklist

The owner ticks these with a dev build or the next release built from this branch; agents never tick them. Mark a
check `- [x] (owner YYYY-MM-DD, Linux/Windows)` when it passed, or leave a note under it when it did not.

## Search

- [ ] `after:` today's date finds mail from just after midnight here (before this change it missed the first hours
      east of UTC). `before:` today's date leaves today's mail out.
- [ ] Search a word: it is lit up in green in the result rows' names, subjects and previews (a row found by a
      word deeper in the body shows none, since the preview is the start of the mail).
- [ ] Open a result: the word is lit up in green in the message, in plain-text and HTML mail.
      Filters (`from:`, `is:unread`) and left-out words (`-paid`) are not lit up.
- [ ] Closing the search and opening the same conversation from the inbox shows no green.

## Links

- [ ] Hover a link in an HTML mail: where it goes shows just under the link (above it near the bottom of the
      window); it goes away when the pointer leaves the link or the pane scrolls.
- [ ] A link whose text is an address of another site (in the fake: the newsletter's "fieldnotes.example/maps")
      shows the warning in yellow; clicking it opens the menu with the warning instead of the browser, and Open
      link there still opens it.
- [ ] An ordinary link ("Read more") still opens in the browser on click.

## Show original

- [ ] A conversation's `…` menu → Show original: the newest message's headers and source show after a moment,
      Copy copies them, Esc closes, and shortcuts like `e` do nothing while it is open.
- [ ] With the network off, it says it could not reach the server instead of hanging.

## Mark all read

- [ ] In the inbox with unread mail beyond the first page, `U` marks all of it read (the unread count goes to 0
      and stays there after the next sync). The server shows them read after the undo window.
- [ ] `z` right after brings every one of them back to unread.
- [ ] `U` in a folder (`g l`) marks only that folder's mail; in search results it does nothing.
