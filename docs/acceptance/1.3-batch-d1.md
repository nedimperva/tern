# Batch D1 (pictures, saved searches, account colours, backup): acceptance checklist

The owner ticks these with a dev build or the next release built from this branch; agents never tick them. Mark a
check `- [x] (owner YYYY-MM-DD, Linux/Windows)` when it passed, or leave a note under it when it did not.

## Pictures in the text

- [ ] Take a screenshot (or copy a picture), click in compose's text and paste: the picture shows in the text where
      the cursor was, no wider than the text, and no attachment card appears for it.
- [ ] Drag a PNG or JPEG from the file manager onto the text: it goes in where it was dropped. Dropped elsewhere
      on compose (the To field, the bottom), it is attached as a file, as before. The drop zone says both.
- [ ] Send it to yourself: the picture shows in the message in Tern, and in another mail client (webmail, phone)
      as part of the text, not as a separate attachment.
- [ ] Click a picture in the text and press Delete: it goes. Send: the message has no picture and no attachment.
      Ctrl+Z after Delete brings it back before sending.
- [ ] Close compose with a picture in it and open the draft again (Drafts): the picture still shows.
- [ ] Pasting text with pictures from a web page brings the text only, no pictures from the web.
- [ ] A very large picture (over 8 MB) says it is too big to put in the text instead of failing silently.

## Saved searches

- [ ] Search `is:unread`: "Save search" shows beside the search box; click it, it says "Saved".
- [ ] Ctrl+\ shows it under Searches in the rail; clicking it runs it (from any folder: over that folder's list).
- [ ] Hovering it in the rail shows ×; clicking × forgets it.
- [ ] Ctrl+K lists saved searches under "Saved searches", and "Save this search" / "Forget this search" while
      searching.
- [ ] Saved searches are still there after a restart.

## Account colours and switching

(Needs two accounts. The browser preview has a second one at `#two`.)

- [ ] Ctrl+\: the rail starts with a badge per account (initials on its colour, a dot when its inbox has unread
      mail). Clicking one opens that account's inbox, and its badge is ringed while you are there.
- [ ] Each account's heading in the rail has its small badge.
- [ ] In All Inboxes, the Important/Other tabs and search, each row has a small dot in its account's colour;
      inside one account's folder there are none.
- [ ] Settings → an account → Colour: pick another; the rail, rows, Settings list and compose's From dot change at
      once. Default takes it back to the original colour.

## Backup

- [ ] Settings → Backup → Export settings…: a save dialog opens with `tern-settings.json`; afterwards it says how
      many snippets and signatures went in. Open the file: no passwords, no AI key.
- [ ] Change the theme and a saved search, then Import settings… with that file: they come back as they were, and
      it says 0 new snippets and 0 new signatures (none were missing).
- [ ] On the other computer (Windows/Linux), with the same account added, Import: settings, snippets, signatures,
      saved searches and account colours arrive. A signature for an account that isn't there is named as left out.
- [ ] Importing a file that isn't Tern settings says so, and changes nothing.
