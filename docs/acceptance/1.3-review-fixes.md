# 1.3 review fixes: acceptance checklist

The owner ticks these with a dev build or the next release built from this branch; agents never tick them. Mark a
check `- [x] (owner YYYY-MM-DD, Linux/Windows)` when it passed, or leave a note under it when it did not. Use the dev
server or a test account for the account checks: removing an account deletes Tern's copy of its mail.

## Accounts

- [ ] Settings → your account → Change password: a wrong password shows the server's refusal and keeps the old
      one; the right one says "Saved" and the status strip goes back to "Up to date".
- [ ] With the password changed on the server first, the strip says to enter the new one in Settings (Ctrl+,);
      entering it there gets mail syncing again without restarting Tern.
- [ ] Remove from Tern… asks again, then removes the account: it leaves the rail, the list and the From picker,
      its password is gone from the keyring (`seahorse` on Linux), and nothing about it shows in the log after.
- [ ] Adding the same account again afterwards syncs it from scratch.

## Mail

- [ ] A message without a Date header (send one with `swaks --header "Date:"` or from a script) lands at the
      time it arrived, not at the bottom. One dated years ahead does not stick to the top.
- [ ] Links in a plain-text mail are underlined and open in the browser; a link at the end of a sentence leaves
      the full stop out.
- [ ] A newsletter or alert with the same subject every week shows as separate conversations from now on (old
      ones already joined stay joined).

## Keys and undo

- [ ] Holding `e` archives one conversation, not one per key repeat; holding `j` still moves down the list.
- [ ] Archive two conversations within five seconds: `z` brings back the second, `z` again the first.
- [ ] With Undo send at 20 seconds, `z` 15 seconds after sending brings the message back into compose.

## Attachments

- [ ] Open a received attachment, then Settings → About: Downloaded attachments shows a size; Clear empties it
      and the attachment opens again (downloads again).
- [ ] Attach with the paperclip, and by dropping a file on the window: both attach. Save on a received
      attachment opens the save dialog and saves there.
- [ ] An `.html` or `.svg` attachment: Open says it could run as a program; Save works; V still shows it as text.

## Security

- [ ] A Linux notification for a mail whose subject has `<b>bold</b>` shows the tags as text.
- [ ] Load images on a mail with `http://` pictures: they still show (asked for over https) when the host has
      https; none are fetched over http (the log or a proxy shows only https).
- [ ] New mail with Write with AI: "write to the IT helpdesk at my company about my laptop" (no address). If it
      makes up an address you don't have in contacts, the panel says it was not added, and Tab leaves it out of To.
      An address you typed in the request is added as before.

## Search (added after 1.3.1)

- [ ] Snooze a conversation, then search `is:snoozed`: it is found. `-is:snoozed` with a word leaves it out.
- [ ] Mark a passage with a note and another without: `has:note` finds only the first, `is:marked` both.
