# 0.3.1: acceptance checklist

The owner ticks these against a real account and a real window; agents never tick them. Mark a check
`- [x] (owner YYYY-MM-DD, account)` when it passed, or leave a note under it when it did not. Each line says what
to do and what to look for. Version under test: 0.3.1, a reading-pane redesign within the focused Linux beta (M2);
see [PLAN.md](../PLAN.md). It replaces the Reading section of [0.3.0](0.3.0.md); the rest of that list still applies.

Unless a line says otherwise, check on Linux (Omarchy/Hyprland). Lines marked **Windows** are for the Windows build.

## One message and the newest message (docs/design/ui.md §4.2)

- [ ] Open a single mail from a person: a 24 px subject, a byline (avatar, name, "to you · 2 hours ago") and the
      text a size larger than before. No card, no outline around it.
- [ ] Open a newsletter: it sits straight on the page with rounded corners, no grey well around it.
- [ ] Open a conversation: the newest message looks exactly like a single mail, at the bottom.

## History above the stage

- [ ] Every earlier message is one line on a soft panel above the newest: avatar, name, first line, date. None
      are hidden; there is no "earlier messages" to click first.
- [ ] Click a line: it opens in place with "to …" and the full date. Click again: it closes.
- [ ] Unread earlier messages start open.
- [ ] `n` / `p` move through the lines: the one the keys act on is a step darker. No blue bar anywhere.
- [ ] Your own messages have a ring on the avatar. Replies days apart show a small "3 days later" label.

## Header icons

- [ ] A newsletter with tracking pixels shows a green shield with a number. Hovering says what was blocked;
      clicking loads the images, and the tooltip then says the trackers are still blocked.
- [ ] `…` lists "Always load images from this sender" while images are blocked.
- [ ] A long mail shows a clock; hovering says "N min read".
- [ ] A designed mail shows a book: it switches reading view on and off; the mail comes back whole each time.
- [ ] A mailing-list mail shows an envelope with a cross: it opens the unsubscribe page (or compose) and turns
      into a check.
- [ ] A mail from a friend shows only Done, `…` and the close cross.

## No outlines

- [ ] Files, the reply row and an inline reply sit on a soft tone, with no border.
- [ ] Beside an open conversation, the list sits on a slightly different tone, with no dividing line.
- [ ] Dark mode: the soft tones are visible but quiet; nothing has a box of a different shade behind its text.

## Version

- [ ] The 0.3.1 installer from the release installs over 0.3.0 and keeps accounts, mail and settings.
- [ ] Building from source: after `cargo clean`, `npm run tauri dev` leaves `target/` at a few GB, not 10+.
