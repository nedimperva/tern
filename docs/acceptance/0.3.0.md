# 0.2.1: acceptance checklist

The owner ticks these against a real account and a real window; agents never tick them. Mark a check
`- [x] (owner YYYY-MM-DD, account)` when it passed, or leave a note under it when it did not. Each line says what
to do and what to look for. Version under test: 0.2.1 (PR #37). These are the first M2 (Linux beta) slices;
see [PLAN.md](../PLAN.md).

Unless a line says otherwise, check on Linux (Omarchy/Hyprland). Lines marked **Windows** are for the Windows build.

## Desktop: tray, notifications, links (package 08)

- [ ] Close the window: Tern stays in the tray and keeps syncing. Clicking the tray icon brings the window back.
- [ ] Tray menu → Quit Tern (or `Ctrl Q`) ends Tern; it is gone from the tray.
- [ ] With the window closed, send yourself a message from another client: a notification shows sender and subject.
- [ ] Click that notification: Tern opens on that conversation.
- [ ] **Windows:** the notification shows. (Clicking it does not open the mail yet; known.)
- [ ] Start Tern a second time while it runs: the existing window comes forward, no second Tern.
- [ ] Settings → Desktop → "Open email links in Tern". Then `xdg-open 'mailto:a@b.c?subject=Hi&body=Hello'`:
      compose opens with To, subject and body filled. Try it once with Tern running and once with it stopped.
- [ ] Settings → Desktop → Start at login on; log out and in: Tern starts in the tray.
- [ ] Settings → Desktop → New mail → "Don't notify me": new mail no longer notifies.

## Triage: Important / Other, snooze (package 05)

- [ ] The inbox shows Important and Other tabs. Newsletters, mailing lists and no-reply senders sit in Other.
- [ ] `Tab` / `Shift Tab` move between Important, Other and Starred.
- [ ] On a newsletter in Other: `Ctrl K` → "Move sender to Important". It moves, and that sender's next mail lands in Important.
- [ ] Same the other way: "Move sender to Other" on a person's mail.
- [ ] Settings → Reading → Inbox → "One list": the tabs go away and everything shows together.
- [ ] `h` on a conversation, type `2m`, Enter: it leaves the list. About two minutes later it is back, unread, with a notification.
- [ ] Snooze something until tomorrow, then reply to it from another client: it comes back at once.
- [ ] `g h` lists snoozed mail with when each comes back; `Shift H` brings one back now.
- [ ] Restart Tern with something snoozed: it stays snoozed and still comes back on time.

## Search speed and snippets (packages 06, 07)

- [ ] Search a word that is in lots of your mail: results appear as you type, without a pause.
- [ ] Newest matches are at the top.
- [ ] `g ;` opens Settings → Snippets. Add `thx` with the text `Thanks {first_name}!`.
- [ ] Write to someone, type `;` at the start of a word: the snippet list opens; arrows and Enter pick one.
- [ ] Type `;thx` then Space: it becomes "Thanks Ada!" (their first name).
- [ ] A snippet with `{cursor}` puts the cursor there; `{subject}`, `{my_name}` and `{date}` fill in.
- [ ] A second snippet with the shortcut `thx` is refused with a message.

## Message view (package 02)

- [ ] A plain reply from a colleague reads in Tern's font and colours, in light and dark mode.
- [ ] A designed mail (newsletter, receipt) keeps its own look in a frame.
- [ ] In dark mode, a designed mail is darkened and stays readable. Settings → Reading → "Designed mail in dark mode" → Original shows it as sent.
- [ ] "Reading view" on a designed mail shows just its text; "Show original" goes back.
- [ ] The quoted part of a reply is folded behind `···`; clicking it shows the quote.
- [ ] Attachments show as cards: a small picture for images already opened once, a coloured badge (PDF, XLSX…) otherwise.
- [ ] Check a few real mails from your inbox; note any that look broken (sender and subject is enough).

## Attachment viewer (package 07)

- [ ] Click a PDF's card (or press `V` in the conversation): it opens inside Tern and the pages show.
- [ ] `→` / `←` step to the message's other files; the top says "2 of 4".
- [ ] A picture fits the window; clicking it shows full size, clicking again fits.
- [ ] A `.txt` or `.csv` file shows inside Tern (a CSV as a table).
- [ ] A Word or Excel file says Tern can't show it and offers "Open with system", which works.
- [ ] `Ctrl S` saves the file shown; `Esc` closes the viewer.
- [ ] **Windows:** a PDF shows in the viewer.

## Quick quote, menu, contact card (packages 02, 07)

- [ ] Select a sentence in a message and press `r`: the reply quotes only that sentence, shown open.
- [ ] `r` with nothing selected quotes the whole message as before.
- [ ] The `…` next to Done lists the conversation's actions with their keys. Arrows and Enter run one; `Esc` closes it.
- [ ] Rest the pointer on a sender's name: after a moment a card shows their address, counts and recent conversations.
- [ ] Click a conversation in the card: it opens.
- [ ] "Write to them" opens compose to them; "All their mail" searches `from:` them; clicking the address copies it.
- [ ] Opening a conversation never pops a card by itself.

## Version

- [ ] The 0.2.1 installer from the draft release installs over 0.2.0 and keeps accounts, mail and settings.
