# 1.4.0 (accessibility, notifications per account, tooling): acceptance checklist

The owner ticks these with a dev build or the release built from this branch; agents never tick them. Mark a
check `- [x] (owner YYYY-MM-DD, Linux/Windows)` when it passed, or leave a note under it when it did not.
Batch D1's checklist (`1.3-batch-d1.md`) covers the rest of what 1.4.0 brings.

## Notifications per account

(Needs two accounts.)

- [ ] Settings → one account → Notifications says "As in Notifications (Important mail)" until you pick.
- [ ] Set one account to None: new mail to it brings no notification; mail to the other account still does.
- [ ] Set an account to Important and Other while Notifications → Notify for says Important mail: a newsletter
      to that account notifies, one to the other account does not.
- [ ] Turn Notifications → New mail off and set one account to Important mail: only that account notifies.
- [ ] Quiet hours keep every account quiet, whatever its own choice.
- [ ] A snoozed conversation coming back, and a follow-up with no answer, follow their account's choice too.

## Keyboard and screen reader

- [ ] Ctrl+\: Tab walks the accounts' badges, All Inboxes, Snoozed, every folder and label; Enter opens the one
      with focus. A saved search's × shows on Tab too.
- [ ] In a conversation, click `…`: the first action has focus; arrows move, Enter runs it, Esc closes and the
      focus is back on `…`.
- [ ] Tab to a sender's name in a conversation, Enter: their card opens. Esc closes it.
- [ ] Settings: Tab reaches each section in the left column; Enter opens it.
- [ ] Settings → an account → Colour: Tab lands on the picked swatch; the arrow keys move to the next colour.
- [ ] Compose → To: type two letters; the arrows move through suggestions, Enter takes one (as before).
- [ ] Attachment viewer on a picture: Z zooms in and out.
- [ ] With Orca (Linux) or Narrator (Windows) on: j and k in the list say the conversation (who, subject, unread,
      place in the list). Optional; skip if you don't use one.
- [ ] Nothing looks different from 1.3 apart from focus rings where Tab lands.

## Release

- [ ] Settings → About says 1.4.0.
- [ ] After merging: push tag `v1.4.0` from your machine; the draft release gets the 1.4.0 notes from CHANGELOG.md.
